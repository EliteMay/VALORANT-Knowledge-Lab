# CONTENT MAP

## Primary Goal

「試合中に、何を見て、どう判断し、味方とどう合わせるか」を学べる構造にする。

用語をABC順に並べることより、実際のGame SituationからConceptへ辿れることを優先する。

## Concept Page Template

### 1. 一言定義
短く、他Conceptとの違いが分かる定義。

### 2. 何のために使うか
Kill以外を含めたRound上の目的。

### 3. Trigger
「この状況なら考える」という開始条件。

### 4. Cues
Minimap、Utility、足音、味方位置、Spike、残り時間、過去Round pattern等。

### 5. Action
観測したCueをどうActionへ変換するか。

### 6. Mistakes
初心者がConcept名だけ真似した時に起こりやすい失敗。

### 7. Conditions / Exceptions
Agent、Map、Team plan、人数、Economy、時間等で変わる点。

### 8. Pro / Match Example
Sourceが確認できる例だけ利用する。

### 9. Practice
Custom / Duo drill / Ranked focus / VOD review question等。

### 10. Evidence
Source type、date、claim、limitation。

### 11. Related Concepts
次に学ぶConceptへのLink。

## Findability

- Category Browse
- Keyword Search
- Related Concepts
- 「状況から探す」導線

Glossaryは補助として持てるが、Primary Navigationには固定しない。
